    Help

    1. Student. Type the name. Choose the assessment.
    2. Record. Press Start recording. Press Stop at the end. If the browser asks about the microphone, choose Allow.
    3. Two voices. Tap Student or Teacher when the speaker changes. Only the student's lines are marked.
    4. Check the transcript. Fix any wrong words. If no words appeared, press Make text from the recording.
    5. Mark. Press Suggest marks. Then check each row and change the number if you need to.
    6. Feedback. Press Write feedback for me. Change the words if you like.
    7. Print or save. Print the report, or save it to this computer with the recording.

    Made a mistake while recording? Press Delete and start again. An Undo button shows for a few seconds.

    Nothing is sent anywhere. Your work is kept on this computer, even if the page closes, until you press Clear all students. On a shared computer, save your work and then press Clear all students when you finish. Work is deleted by itself after 30 days.
